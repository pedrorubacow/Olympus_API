# Como contribuir

Fluxo de trabalho deste repositório:

1. Nunca commitar direto na `main`.
2. Criar uma branch por funcionalidade: `git checkout -b feature/nome-da-coisa`.
3. Commitar usando Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`).
4. Subir a branch: `git push -u origin feature/nome-da-coisa`.
5. Abrir um Pull Request no GitHub.
6. Revisar, mergear (`Merge pull request` → `Confirm merge`).
7. Voltar pra `main` e atualizar local: `git checkout main && git pull`.

Cada fase do projeto (ver `docs/`) vira uma branch e um PR.
